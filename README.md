# In Falsus 製卡最佳化

輸入「板子＋粒子庫存」，算出最佳的粒子擺放。不需要安裝任何東西，也不會碰遊戲。

## 開啟
- **桌面版**：雙擊 **`InFalsusSolver.exe`**（`npm run build:desktop` 產生在 `release/`，單一檔案，內建原生多執行緒求解器，最快）。
- **網頁版**：雙擊 **`infalsus_solver.html`**（Chrome / Edge / Firefox 都可以）。資料會自動存在瀏覽器裡。
- 線上版：https://infalsus-solver.ncc3-quiz.workers.dev （Cloudflare Worker，WASM 求解）。

## 三步驟
第一次打開已經載入**預設配方的板子**和**最新的粒子庫存（五色共 30 種）**，只差填數值：

1. **選配方**：頂端下拉選單選一個配方按「載入」（預設有「找尋夥伴的溫暖目光」「新朋友」）。
   新配方用 **📷 截圖匯入**：選圖、Ctrl+V 貼上，或直接把截圖拖到板子上。
2. **填區域數值**：右側「區域」分頁。在遊戲裡把滑鼠移到區域上會顯示「攻擊力 +x／防禦力 +y」。
   Enter 跳下一格；點板子上的區域也會跳到對應那一列；「快速輸入」可一次貼上多行（每行「攻擊 防禦」）。
3. **按 ▶ 求解**（Ctrl+Enter）。擺放結果直接畫在左邊的大板子上：每顆粒子有編號與外框，區域打 ✓，
   右上角顯示最終攻擊／防禦。

> 內建粒子庫存只有「一般粒子 30 種」和「含額外粒子 40 種」兩組，「只用這一組」可以直接切換；懲罰一律照「超界、重疊、乖離、過載」的順序顯示。
> 「結果」分頁右邊面板自動放寬，擺放說明的步驟卡與小地圖比較大（標題旁「⇔」可切回窄版）。
> 下面幾段對免除的說明是舊版介面的描述。
- **頂端常駐列**：配方、截圖匯入、粒子上限、最佳化目標、求解、三種目標比較、停止。手機上會有浮動的「▶ 求解」。
- **狀態列**：板子幾格幾區、區域數值填了幾個、粒子幾種幾色；紅／黃色代表還缺東西，點一下跳到對應分頁。
- **板子**：預設「檢視」模式，拖曳平移、滾輪縮放、點區域選取，**不會誤改格子**。要改板子按「編輯板子」
  （塗色、橡皮擦、區域標籤；Ctrl+Z 復原；右鍵或空白鍵拖曳平移）。
- **右側分頁**
  - **區域**：各區域的攻擊／防禦，缺同色粒子的區域會警告。每個區域還有：
    - **🔒 一定要觸發**：勾選後，求解結果「一定」會把這個區域填滿（想拿它的特殊效果時用）。
      可以勾多個；板子上這些區域會標 🔒。如果在粒子數上限與懲罰限制內放不下，結果會顯示「無解」，
      不會硬給一個沒填滿的擺放——這時請取消其中幾個，或放寬「設定」。攻擊／防禦可以留 0，仍然會被填滿。
    - **🎯 任務條件（區域分頁最上方）**：填「基礎防禦至少」、「基礎攻擊至少」、「總懲罰最多」（可以同時設；前兩個 0 或留空＝不限制，
      「總懲罰最多」留空＝不限制、填 0＝遊戲任務常見的「總懲罰數為 0」，免除懲罰生效之後的有效懲罰才算）。
      「基礎」就是遊戲左邊面板的「基礎攻擊力／基礎防禦力」＝**填滿的區域**的攻／防加總，和平均效能、懲罰倍率無關。
    - **✦ 特性槽／範圍、🔗 合併**：每個區域可以填「特性槽＋」「範圍 左＋／右＋」（遊戲把滑鼠移到區域上會看到），任務條件另有「特性槽至少」「範圍左至少」「範圍右至少」
      （遊戲任務「特性槽為 3 以上」「卡牌範圍（左）為 3 以上且（右）為 3 以上」；範圍左右各最多 4），算的是**填滿的區域**的加總，也是硬性條件，
      求解仍然是最優（在 `Solver.solveTraits` 用分支定界：引擎一次只解「一定要填滿某些區域」的問題）。
      兩個同色區域也可以「🔗 合併」成同一個區域（要一起填滿才算，共用最前面那區的攻防／免除／特性）。
      這是硬性條件：求解只在達標的擺放裡，照「最佳化目標」找最好的。放不下時顯示「無解」：
      門檻比所有能填的區域加總還高會直接告訴你上限；其他情形（粒子數上限、懲罰、粒子不夠）請降低門檻或放寬「設定」。
      結果的「基礎 攻／防」那一列會標 ✓，紀錄分頁與 CSV 也會記下當時的門檻。
      **🛡 固定免除**（同一個框）：角色技能、卡牌效果之類「一直生效」的免除，**不用填滿任何區域**；選種類（整體／乖離／過載／重疊）和點數。
      被免除的那幾點不算懲罰（遊戲面板懲罰旁邊有空的免除格就是這個）。選「整體」或「重疊」時會**自動允許重疊**（一次免費的重疊可以接受，超過的照樣扣）。
      固定免除**可以同時有好幾種**（整體、乖離、過載、重疊、超界各填各的點數），再加上各區域的免除一起算。
      **超界**：設定分頁的「允許超界擺放」開啟後，粒子可以部分放到板子外面（任何一格在板外的粒子 +1「粒子超界」，完全在板外是「虛偽錯誤」不會用）；
      有「超界」免除時會自動開啟。假設：板外的格子和板內一樣會算重疊、相連（乖離）。開啟後搜尋會慢很多（板外多了好幾圈格子），不需要就別開。
      **無解時會自動診斷**：逐一檢查每個區域「單獨」能不能填滿（沒有同色粒子／形狀拼不出來／超過粒子數上限），
      並告訴你能填滿的區域加總夠不夠門檻，不用再猜是哪裡卡住。
    - **🛡 免除［整體／乖離／過載／重疊／超界］懲罰 N 點**：特殊效果之一。這個區域填滿後免除 N 點懲罰（最低到 0）。
      **預設是「整體」**：從總懲罰扣，不分種類（乖離、過載、重疊哪種都可以抵銷）；也可以改成只免某一種。
      多個區域的免除會加總；「只免某一種」的各種類各算各的、不能互相抵銷，扣完之後「整體」的點數再從剩下的總和裡扣。
      免除「過載」或「整體」會讓可以多放的粒子變多（粒子數上限＋可承受的懲罰＋免除點數）。
      免除「重疊」要在「設定」分頁開啟「允許重疊」才有用（預設不允許重疊）。填 0 或留空代表沒有這個效果。
      結果的「懲罰」那一列會寫出「🛡免除 過載 −2」，板子上的區域標 🛡載2（乖／載／疊）。
    - **其他特殊效果（備註）**：只是記事用的文字欄，不影響計算。特殊效果**目前都不算進攻防分數**，只有上面兩項（必觸發、免除懲罰）會影響擺放。
  - **粒子**：預設粒子圖塊，點形狀加入／移除，加入後可直接改效能（`133x3, 120x10`＝效能x數量）。
    每個顏色旁的開關決定「這次求解用不用該色」，庫存不會刪。可切換「最新庫存」「較早庫存」、自訂粒子（自己畫形狀）。
  - **結果**：每次求解的記錄，點選任一筆，板子上的擺放就換成那一筆；下面是填滿的區域、平均效能、懲罰，以及
    **🧩 怎麼擺**：
    - 板子上每顆粒子有彩色外框、編號和**效能數字**；滑鼠移到（或點一下釘選）某一步，板子上其他粒子會變淡、那顆亮起。
    - 先列出要從庫存取哪些粒子（同形狀合成一堆，效能由高到低；挑該堆「最高」的那顆依序取）。
    - 每顆一張步驟卡：粒子圖形（照圖的方向放、不旋轉）、顏色與格數、效能、蓋住哪些區域（幾格／總格數），
      以及一張**整張板子的小地圖**（這顆亮起、其他顆淡淡標出）。
    - 最後是「放完後，遊戲左邊面板應該顯示」：已使用粒子數、平均效能、各種懲罰、攻擊力／防禦力，
      可以和遊戲對照來確認有沒有放錯。「📋 複製」可以把整份清單複製成文字。
  - **地圖**：把**目前的板子＋各區域數值**（攻防、必觸發、免除、備註）＋**任務條件、固定免除、粒子上限、目標等設定**一起存成一張地圖，
    載入用畫面最上方的地圖選單；這裡可以覆蓋、刪除、加備註，每列「匯出」只存那一張。
    全部地圖的匯出、各區域數值 CSV、匯入檔案都在「⋯ 更多」（換電腦或換瀏覽器前記得匯出：線上版和本機檔的資料不會互通）。
    內建地圖只列在最上方的地圖選單裡。
  - **紀錄**：每次求解完成（「三種目標比較」的每一筆也算）的攻擊／防禦會**自動記下來**，關掉網頁也還在
    （存在這個瀏覽器的 localStorage）。每筆有時間、配方、目標、攻防、基礎值、平均效能、倍率、懲罰、填滿的區域
    （含當時的區域數值）與完整粒子清單；配方名稱可以自己改（板子沒改過才會自動帶入載入的配方名稱），也能寫備註。
    完全相同的擺放只累計「重複次數」，不會重複記。每筆展開後有「🗺 載入當時的地圖與數值」，可以把板子、數值與任務條件還原成求解當時的樣子。上方有各配方的筆數與最高攻／防小計，**匯出 CSV** 可用 Excel 開啟。
    「匯出全部資料」會連紀錄一起帶走，匯入時依 id 合併；「還原成初始狀態」不會清掉紀錄，只有「清除全部」會。
  - **設定**：旋轉、重疊、懲罰倍率（公式或自訂表）、自訂權重、搜尋時間。
- **三種目標比較**：分別用「平衡／攻擊特化／防禦特化」各算一次，並排比較；每欄最高值用粉紅色標出。
- **⋯ 更多**：匯出（全部資料／只有粒子庫存／只有地圖／目前區域數值 CSV）、📂 匯入檔案（自動分辨是全部資料、粒子庫存還是地圖檔，只更新檔案裡有的部分）、還原成初始狀態。

## 最佳化目標
- 平衡：攻擊＋防禦總和最大。
- 攻擊特化：先求攻擊最大，一樣時才比防禦（防禦特化相反）。
- 自訂權重：目標 = 攻擊×權重 + 防禦×權重。

## 目前採用的規則（實測，詳見 `notes_cards_and_crafting.md`）
- 區域內每一格都被**同色**粒子蓋住 → 該區域填滿，加上它的攻／防。
- 最終 = 基礎 × (平均粒子效能/100) × 懲罰倍率；倍率 = 1 − (P/3)²。
- P = 過載（超過粒子數上限）＋重疊＋乖離（互不相連的粒子群數 − 1）；超界不會被選用。
- 粒子**不能旋轉**，形狀方向固定。
- 額外粒子（沒蓋在任何區域上）若效能高於目前平均，可以拉高平均，或用來連接分離的粒子群。
- 「免除懲罰」：每種懲罰各自 max(0, 該種懲罰 − 已填滿區域對該種的免除點數)，三種加起來，再減去「整體」免除點數（最低 0），
  才是用來查倍率的懲罰；懲罰上限（P ≥ 3 無法製作）也是看扣掉免除之後的值。每個區域免除哪一種（預設整體）由你在區域列自己選。
- 「一定要觸發」的區域是硬性條件：求解只在「這些區域都填滿」的擺放裡找最大值（其餘區域照樣可選）。
- 「總懲罰最多 N」：有效懲罰（扣掉免除之後）超過 N 就當作無法製作，等於把懲罰上限降到 N＋1；粒子數上限也跟著收緊。
- 「任務條件」（基礎攻防門檻）也是硬性條件：只在「填滿的區域攻／防加總 ≥ 門檻」的擺放裡找最大值；門檻判斷用的是基礎值，不是最終值。

## 需要你確認的假設
- **異色粒子放在灰格也計入平均效能**：求解器會拿其他顏色的高效能粒子墊高平均。尚未用遊戲驗證；
  想避開就在「粒子」分頁只開啟與區域同色的顏色。
- 乖離是否只看「邊相鄰」：目前是。
- 同形狀的粒子堆疊，求解器假設每顆的效能就是你填的清單（用最高的那幾顆）。

## 部署（Cloudflare Worker＋WASM）
- 線上版：**https://infalsus-solver.ncc3-quiz.workers.dev**（靜態資產型 Worker，設定在 `wrangler.jsonc`，安全標頭在 `worker/_headers`）。
- 求解核心有兩個版本，結果完全一樣：JS（`src/solver.js` 的 `searchJS`）與 **WASM**（Rust 寫的，`wasm/src/lib.rs`，逐行對照移植）。
  網頁在瀏覽器的背景執行緒裡用 WASM 求解（通常快 1.5～3 倍），載入失敗或發生例外時自動退回 JS；「設定」分頁可以手動關掉 WASM。
  搜尋法是「區域組合＋鋪法輪廓上界」（說明在 `src/solver.js` 的 `buildPlan` 前面的註解；效能紀錄與前後對照在 `notes_perf.md`）：
  110 格 14 區的大板子單執行緒約 0.02～0.3 秒就能跑完並證明最佳。區域超過 20 個時退回舊版的搜尋。
  求解不在 Worker 伺服器端跑（Worker 有 CPU 時間限制，求解要好幾秒），所以不吃伺服器額度。
- `npm run deploy`：重新建置後 `wrangler deploy`（要先 `npx wrangler login`）；`npm run dev`：本機用 `wrangler dev` 預覽。
- `wasm/solver.wasm`（約 120 KB）**有提交進 repo**，所以沒有裝 Rust 也能 build／部署；改了 `wasm/src/lib.rs` 才需要 `npm run build:wasm`
  （要 Rust 與 `rustup target add wasm32-unknown-unknown`），之後要再 `npm run build` 才會嵌進網頁。

### 本機：原生多執行緒（用滿所有 CPU 核心）
- 想在自己的電腦上算得更快：`npm run build:native`（要 Rust；產生 `wasm/target/release/solver_native`），再 `npm run local`，
  用瀏覽器開 **http://localhost:8765**。網頁偵測到本機的原生求解器，「設定」分頁會出現「使用原生多執行緒」和執行緒數（空白＝全部核心）。
- 原生求解器是同一份搜尋核心的 Rust 原生版：多個執行緒**共用目前最佳值**（互相幫忙剪枝）、動態認領第一層的候選擺放，所以能用上所有核心；
  瀏覽器的 WASM 只能單執行緒。換了新的搜尋法之後，大部分題目單執行緒不到 0.1 秒就跑完，原生版多出來的主要是固定開銷；
  多執行緒對特別難的題目（例如開了旋轉的大板子、鋪法特別多的板子）才有明顯幫助（實測 2～5 倍）。
- 本機伺服器只綁 127.0.0.1，網頁和求解器都在你的電腦上；原生版不可用（沒編、被關掉）時自動退回 WASM。**GPU 不適合**這種分支定界搜尋（流程不規則、要共用最佳值剪枝），所以沒做。

### 桌面版（單一 exe，不需要瀏覽器、Node、本機伺服器）
- `npm run build:desktop`（要 Rust）→ **`release/InFalsusSolver.exe`**（約 1.4 MB），雙擊就能用。
  Rust 原生視窗，介面用 Windows 內建的 WebView2（Windows 11 本來就有），原生多執行緒求解器就內建在同一個 exe 裡
  （求解時它以 `--solve` 模式啟動自己當子行程；按「停止」就把子行程殺掉）。
- 資料存在 `%LOCALAPPDATA%\InFalsusSolver`，和瀏覽器裡的資料是分開的：想把舊資料搬過來，在舊的地方按「匯出」，到桌面版按「匯入」。
- 程式在 `desktop/`（`wry`＋`tao`），網頁是編譯時內嵌的，所以改了網頁要重新 `npm run build:desktop`。

## 限制
- 搜尋有時間上限；很大的板子或很多種粒子時可能跑不完，畫面會顯示「時間到：目前最佳」，不保證最優。
- 用額外粒子連接分離粒子群時，最多考慮距離 5 格內的橋接。
- 區域特性目前只做「特性槽」與「卡牌範圍（左／右）」（填滿該區域時各加幾點，任務條件可設門檻）；「轉色」等其他特性、粒子本身的特性還沒做，
  區域的其他特殊效果只能用「一定要觸發」強制填滿或寫在備註。
- 截圖只能匯入**板子**；粒子庫存的形狀和區域的攻防數值還是要手動（圖示太小且縮放不一致，數值在截圖上也看不到）。
- 截圖匯入：兩個同色區域若剛好相鄰會被合成一個，匯入後請在編輯模式用「區域標籤」分開；被遊戲提示框蓋住的格子偵測不到。
